# Bruno Garcia Siviero — Portfólio

Portfólio de desenvolvimento mobile, web e inteligência artificial, com identidade visual inspirada na Technitrix.

**Acesse:** https://bruunoxd.github.io/portf-lio/portfolio.html

## Estrutura
- `index.html` e `portfolio.html`: página completa; mantenha ambas sincronizadas ao editar.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: filtros de projetos, menu móvel e contato.
- `assets/`: imagens e fontes usadas pelo novo layout.
- `IMG/`: imagens anteriores preservadas.

Site estático, sem instalação ou compilação. Abra `index.html` no navegador ou use um servidor estático local. O conteúdo é publicado pelo GitHub Pages.

## Contato
O formulário prepara uma mensagem para o WhatsApp; o visitante revisa e confirma o envio. Não há armazenamento dos dados nem envio automático de mensagens.

## Projetos
Sete projetos com imagens e links originais. Protótipos e trabalho acadêmico em equipe estão identificados. As demonstrações abrem no YouTube; os arquivos de Kanban Help Desk e Insta Tracker estão no MediaFire.
